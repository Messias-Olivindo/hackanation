## Private Directory (Individual Use)

The `private/` directory is reserved for individual team members' personal notes, planning documents, and working drafts that:
- Contain personal thoughts and ideas
- Include work-in-progress plans
- Contain sensitive or preliminary information
- Are not ready for team sharing

**Important**: Files in the `private/` directory should NOT be shared with the team or used as context for AI tools collaborating with the team. This directory is for individual use only and should remain local to each developer's workflow.

## Usage Guidelines

1. Always consult this index before starting any new work
2. Use the templates for consistent documentation
3. Check the version history before making significant changes
4. Reference the specifications when implementing new features
5. Update documentation when making code changes
6. Keep personal notes in the `private/` directory - do not share them with the team

## AI Best Practices

- Use the context files as your primary source of truth
- When in doubt, refer to the project specifications
- Maintain consistency with existing templates
- Document all changes in the version history
- Keep all documentation up-to-date
- Never use files from the `private/` directory as context for team collaboration
